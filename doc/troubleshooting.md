## Troubleshooting

This page lists the error messages and warnings Iris raises, what each means, and what to do. The messages are quoted as the code produces them, with the variable parts in `<angle brackets>`. Installation problems are covered in the [installation guides](installation/README.md), each of which ends with its own troubleshooting table.

### Reading the files

These are raised by `read_table` and `read_pairs`.

| What you see | What it means | What to do |
|---|---|---|
| `<path>: no column '<id_col>' to use as the id; columns: [...]` | The table's id column has another name. | Pass its name, as in `read_table(path, id_col='product_id')`. |
| `<path>: no column(s) [...]; columns: [...]` | `columns` names attribute columns the table does not have. | Use the names listed. |
| `<path>: has both '_id' and the id column '<id_col>'; read it with id_col='_id', or drop one of them` | The file has a column `_id` in addition to the id column named by `id_col`. | Read it with `id_col='_id'`, or remove one of the two columns. |
| `<path>: has none of the pair columns id1/id2, a_id/b_id, ltable_id/rtable_id or left_id/right_id, nor the grouped columns 'id2' and 'id1_list'; columns: [...]. Name the file's two id columns with columns=(...)` | The pairs' id columns have names that are not recognized. | Pass them, table A's first, as in `read_pairs(path, columns=('product_a', 'product_b'))`. |
| `<path>: has no columns [...]; columns: [...]` | The columns given with `columns` are not in the file. | Use the names listed. |
| `<path>: no column 'label' to read with with_label=True; columns: [...]` | The file has no label column. | Leave out `with_label`, or name the label column `label`. |
| `<path>: is named .parquet but does not hold Parquet data; if it is CSV or TSV text, rename it to end in .csv or .tsv` | The contents of the file do not match its name, often because a blocker wrote CSV under a `.parquet` name. | Rename the file as the message says. |
| `<path>: is named .<extension> but holds Parquet data; rename it to end in .parquet` | The file holds Parquet data under a `.csv`, `.tsv` or `.jsonl` name. | Rename it to end in `.parquet`. |
| `<path>: tables and pairs are read from a .parquet, .csv, .tsv or .jsonl file, or a directory of Parquet files` | The file has another extension. | Convert it to one of these formats. |
| `<path>: the file has no header row` | The CSV or TSV file is empty, or its first line is blank. | Add a first line with the column names. |
| `<path>: the file is not UTF-8 text (<reason> at byte <n>); write it as UTF-8, or as Parquet`, `<path>: the file holds text that is not UTF-8; write it as UTF-8, or as Parquet` or `<path>: row <n> (the header is row 1) holds text that is not UTF-8 in the column '<column>'; write the file as UTF-8, or as Parquet` | A CSV, TSV or JSON Lines file holds bytes that are not UTF-8 text, as a file saved in another encoding does. | Save the file as UTF-8, or convert it to Parquet. |
| `<path>: row <n> (the header is row 1) holds '<value>' in the column '<column>', which Iris reads as <whole numbers or numbers>; correct or remove that row` | An id of a CSV or TSV file is not a whole number, such as `abc` or `1.5`, or a label is not a number. | Correct or remove the row. A table keyed by strings is given integer ids as [Tables keyed by strings](technical-guide.md#tables-keyed-by-strings) describes. |
| `<path>: row <n> (the header is row 1) has <n> field(s) where the header has <n>: '<text>'; quote the values that hold <a comma or a tab>, or correct that row` | A row of a CSV or TSV file has more or fewer values than the header has columns, often because a value holds the delimiter and is not quoted. | Quote the values that hold the delimiter, or correct the row. |
| `<path>: the column '<column>' holds a <type> on some line, where Iris reads a whole number; give the column one JSON type on every line, or write the file as Parquet` or `<path>: a line holds <value> in the column '<column>', which Iris reads as <whole numbers or numbers>; correct that line, or write the file as Parquet` | A key of a JSON Lines file has values of different JSON types on different lines, or a line holds an id that is not a whole number or a label that is not a number. | Give the key one JSON type on every line, or convert the file to Parquet. |
| `<path>: a line is not valid JSON (<detail>); write one JSON object on each line` or `<path>: a line holds a <type>, and each line of JSON Lines holds one object; write one JSON object on each line` | A line of a JSON Lines file is not a JSON object. | Write one JSON object on each line. |
| `<path>: cannot be read as <format>: <detail>; correct the file, or write it as Parquet` | `pyarrow` could not read the text file, for the reason that `<detail>` gives. | Correct the file, or convert it to Parquet. |
| `df_type is 'pandas', 'arrow' or 'sparkdf', got '<value>'` | An unknown kind of result was asked for. | Use one of the three. |

### Checking the inputs

These are raised by the `check_*` functions, and by `featurize` before any work.

| What you see | What it means | What to do |
|---|---|---|
| `<table> must have an '_id' column; got [...]` | The table's id column is not named `_id`. | Read the table with `read_table(path, id_col=...)`, which renames it. |
| `<table> '_id' has <n> null value(s); every record needs an id` | Some rows have no id. | Fill them in. Every record needs a distinct integer id. |
| `<table> '_id' must be an integer column (ids are int64 join keys), got <type>; a table keyed by strings is given integer ids as 'Tables keyed by strings' in the technical guide describes` | The ids are text or floating-point numbers. | Give the table integer ids as [Tables keyed by strings](technical-guide.md#tables-keyed-by-strings) describes, and the candidate set and the gold set the same ids. |
| `<table> '_id' must be non-negative; <n> negative id(s), e.g. ids [...]` | Some ids are below zero. | Renumber the ids from zero, and the ids of the candidate set and the gold set with them. |
| `<table> '_id' must be unique; <n> duplicate row(s), e.g. ids [...]` | Two rows share an id. | Give every record a distinct id. |
| `<table> '_id' must be unique; e.g. ids [...] repeat` | `featurize` found two rows that share an id. It checks this on either engine, even with `validate=False`. | Give every record a distinct id. |
| `<table> has columns of the same name: [...]; give each column its own name` | A table given to `featurize` on the local engine has two columns with the same name, among `_id` and the columns that the features read. | Rename one of the two columns. |
| `<table> is empty` | The table has no rows. | Check the path and the filter that produced the table. |
| `candidates must be flat (columns 'id1', 'id2' -- one row per pair) or grouped (columns 'id2', 'id1_list' -- one row per B record); got [...]` | The candidate set has neither accepted shape. | Read the blocker's output with `read_pairs(path, columns=(...))`, which names its id columns `id1` and `id2`. |
| `candidates set is empty: there is nothing to match` | The candidate set has no pairs. | Check the blocker's output. |
| `candidates contain null ids (<n> in id1, <n> in id2)` or `candidates contain <n> null id(s): every pair needs two ids (iris.check_candidates reports them)` | Some pairs lack an id. | Drop those rows. |
| `candidates_from_flat: '<a_col>' and '<b_col>' must not hold null ids` | Some pairs given to `candidates_from_flat` lack an id. | Drop those rows. |
| `candidates '<id1 or id2>' must be an integer column matching <table_a or table_b>._id, got <type>` or `candidates '<id1 or id2>' must be an integer column matching <table_a or table_b>._id (<type>), got <type>` | The ids of the candidate set are text or floating-point numbers. | Give the candidate set the integer ids of the tables, as [Tables keyed by strings](technical-guide.md#tables-keyed-by-strings) describes. |
| `candidates 'id1' references id(s) not present in table_a's '_id' column, e.g. [...]. Every pair must point at records that exist.` | The candidate set names records that the table does not have, usually because the table was filtered or the candidate set belongs to other tables. | Use the tables the blocker ran on. |
| `candidates 'id2' must be unique (one row per B record); <n> duplicate row(s)` | A grouped candidate set lists a record of B on more than one row. | Merge those rows, or convert the candidate set to the flat form. |
| `candidates: <n> self-pair(s) (id1 == id2). featurize drops them when one table is matched against itself, and clean_candidates(..., drop_self_pairs=True) removes them from the candidate set.` | A warning in a deduplication. A record is paired with itself. | Nothing for `featurize`. To remove them from the candidate set itself, use `clean_candidates` as the message says. |
| `candidates: <n> row(s) contain duplicate ids within 'id1_list'; duplicates can be labeled twice and leak between training and application sets. clean_candidates removes them.` | A warning. A grouped row lists the same record twice. | Clean the candidate set with `clean_candidates`. |
| `labeled_data must have the column '<label>'; got [...]` | The labeled pairs have no label column of that name. | Name the column `label`, or pass its name as `label_column`. |
| `<input> is an Arrow dataset and other inputs are Spark DataFrames: pass all inputs local or all as Spark` | Some inputs of one call are Arrow datasets and others are Spark DataFrames. | Read every input of the run with the same `df_type`. |

### Features and feature vectors

| What you see | What it means | What to do |
|---|---|---|
| `column '<column>' is <type>, which has no text form in Iris (supported: <types>). Leave it out of the feature columns, or convert it first.` | A column has a type that Iris cannot compare, such as a nested list. | Leave the column out of the columns given to `create_features`, or convert it to text. |
| `column '<column>' holds <what> <value>, outside the years 1 to 9999 that Iris can show as text` | A date or time column holds a value outside the supported range. | Fix or remove the value. |
| `column '<column>' is date64 with values that are not whole days; store it as a timestamp, or as date32` | A `date64` column holds times of day, which a date cannot show. | Store the column as a timestamp, or as `date32`. |
| `column '<column>' holds text that is not valid UTF-8 (<error>); decode it, or replace the bad bytes, before Iris reads it` | A text column holds bytes that are not UTF-8 text. | Decode the column from the encoding it was written in, or replace the bytes that are not UTF-8. |
| `column '<column>' cannot be read as one type (<error>); it holds [...]: convert it, for example with .astype(str)` | A pandas column holds values of several types, such as numbers and text. | Convert the column to one type, as the message says. |
| `table <A or B> has no column(s) [...] (columns: [...])` | `create_features` was given a column that the table does not have. | Use the names listed. |
| `the columns to match of table <A or B> include '_id', the id of each record; leave it out` | `_id` was given among the columns to compare. | Leave `_id` out of `a_cols` and `b_cols`. |
| `table <A or B> has columns of the same name: [...]` or `table <A or B> has column names that are not strings, e.g. [...]; name its columns with strings` | A table given to `create_features` has two columns with the same name, or a column named by a number or another object. | Give every column a distinct name that is a string. |
| `sim_functions holds token similarity classes, such as those of get_base_sim_functions(); <name> is not one` | `sim_functions` holds something other than a similarity class, such as an instance of one or a tokenizer. | Pass classes, such as those that `get_base_sim_functions()` returns. |
| `<tokenizer> takes a whole number of at least 1, got <n>` | A tokenizer was created with a size that is not a whole number of at least 1, such as 0 or 2.5. | Give a whole number of 1 or more. |
| `column '<column>': <features> compare every character of one value with every character of the other, and its longest values, of <n> and <n> characters, make one pair <n> character comparisons for each. Leave these features out, or shorten the longest values, if featurize is too slow.` | A warning from `create_features`. The edit-distance and Smith-Waterman features of the column take time in proportion to the product of the lengths of the two values, so one pair of long values can take minutes. | If `featurize` is too slow, remove those features from the list, as [Editing a set of features](technical-guide.md#editing-a-set-of-features) describes, or shorten the longest values. |
| `featurize was given no features: create_features made none, when every column is mostly null (null_threshold) or none is chosen; pick other columns, or raise null_threshold` | The list of features is empty. | Give `create_features` columns that have values, or raise `null_threshold`. |
| `featurize with pandas A and B would bring <n> feature vectors of <n> values into this process, about <x> GiB, more than the <y> GiB Iris plans to use (<source>). Pass A and B as Arrow datasets (parquet) to keep the feature vectors on disk.` | With pandas tables, `featurize` returns the feature vectors in memory, and they would not fit. | Read the tables with `df_type='arrow'` and pass `out`, as [Options for large runs](technical-guide.md#options-for-large-runs) describes. |
| `<path>: holds features in format <n>, written by Iris <version>; this Iris <version> reads formats up to <n>: load them with the Iris that wrote them, or a later one` | The file of features was written by a later version of Iris. | Load it with that version of Iris or a later one, or create the features again. |
| `<path>: begins as a file of save_features but its description is damaged; write the features again with save_features` | The first two lines of the file of features, which `save_features` writes, have been changed or cut. | Save the features again with `save_features`. |
| `features read column(s) [...] that <table> does not have (columns: [...])` | The features were created for other tables, or loaded from a file saved for other data. | Create the features from the tables being featurized. |
| `unknown id(s) [...] (<n> total) not in <table_a or table_b>: the pairs point at records that do not exist. Run iris.check_candidates(candidates, A, B) before featurizing to catch this up front.` | `featurize` was called with `validate=False`, and the candidate set names records that the table does not have, usually because the table was filtered or the candidate set belongs to other tables. | Use the tables the blocker ran on. `check_candidates` lists the missing ids. |
| `the vocabulary for '<column>'/'<column>' with tokenizer <tokenizer> is empty after filtering (min_doc_freq=<n>, max_vocab_size=<n>). Lower min_doc_freq or raise max_vocab_size.` | Every token of the column was filtered out, or the column has no values in either table, as when features saved for other data are used on tables where that column is empty. | If the column is empty, leave it out of the features. Otherwise lower `min_doc_freq` or raise `max_vocab_size` in `create_features`. |
| `numeric_threshold is a rate in [0, 1] or None, got <value>` | `numeric_threshold` was given as a percentage or as text. | Pass a fraction such as 0.9, or `None` to detect numeric columns by type only. |
| `unknown timezone '<name>': use an IANA zone name such as "UTC" or "Europe/Paris"` | The `timezone` argument names no time zone. | Use a name from the IANA time-zone database. |
| `featurize: <n> of <n> candidate pairs are repeats and are dropped; each distinct pair is featurized once` | A warning. The candidate set lists some pairs more than once. | Nothing. To remove the repeats from the candidate set itself, use `clean_candidates`. |
| `featurize: one table is matched against itself: <n> pair(s) of a record with itself and <n> repeated or mirrored pair(s) are dropped, and each pair is featurized once, as (smaller id, larger id)` | A warning in a deduplication. The candidate set holds pairs of a record with itself, or the same pair in both orders. | Nothing. To clean the candidate set itself, use `clean_candidates(candidates, drop_self_pairs=True, canonicalize_mirrors=True)`. |

### Disk, memory and workers on one machine

| What you see | What it means | What to do |
|---|---|---|
| `not enough free disk space for Iris scratch files in '<directory>': need <x> GiB, <y> GiB available. These files are memory-mapped, so the space is needed regardless of available RAM. Set IRIS_SPILL_DIR to a directory on a larger volume, or free space on this one.` | The local engine checked the disk before writing its scratch files, and the space is short. | Set `IRIS_SPILL_DIR` as the message says. |
| `not enough free disk for <what> in '<directory>': need about <x>, <y> free. The need counts <parts>, which <step> writes there. Set IRIS_SPILL_DIR to a directory on a larger volume, or free space.` | The same check, made before a step starts and before each of its parts, such as the record stores or the candidate pairs. The need is the most the step holds there at once, so it counts the parts that come later. | Set `IRIS_SPILL_DIR`, or write the output with `out` to a larger volume. |
| `not enough free disk for the rest of <what>, at the <x> its first <p>% took in '<directory>': need about <y>, <z> free. Set IRIS_SPILL_DIR to a directory on a larger volume, or free space.` | A part that Parquet compresses, such as the feature vectors, the sorted candidate pairs, the predictions or a staged copy of an input, is checked once its first part is written, at the bytes that part takes. The rest does not fit. | Set `IRIS_SPILL_DIR`, or write the output with `out` to a volume with the room the message names. |
| `<step> ran out of disk space in '<directory>'. When it checked <what>, it estimated about <x> would be needed there, and <y> was free; the data needed more than that. Set IRIS_SPILL_DIR to a directory on a larger volume, or free space.`, `<step> ran out of disk space in '<directory>' while it wrote <what>, before a first part of it was done to measure the room it needs; <x> is free now. ...` or `<step> ran out of disk space in '<directory>', where it had made no estimate; <x> is free now. ...` | The disk filled while the step ran, because the data needed more space than the step estimated from it, or because the first part of what it wrote did not fit. The step removed its scratch files. | Set `IRIS_SPILL_DIR` to a volume with more room than the message names, or free space, and run the step again. |
| `a worker process died running task <n>; rerunning it with up to <n> task(s) at once` or `a worker process ran out of memory running task <n>; rerunning it with up to <n> task(s) at once` | A warning. A worker process ended, or ran out of memory, before it finished its task. The task runs again, with fewer tasks at once. | Nothing, unless it repeats. Then see the row after the next. |
| `the run held <x> GiB, over its <y> GiB: stopped the newest task to rerun it with up to <n> task(s) at once` | A warning. The processes of the run held more memory than its limit, which `iris info` shows, so the local engine stopped the task it started last, to run it again with fewer tasks at once. The run continues, more slowly. | Nothing. To let the run use more memory, close other programs, or raise `IRIS_MEMORY_GB` when it is set lower than the memory of the machine. |
| `worker processes died <n> times running task <n> alone; ...` or `task <n> ran out of memory <n> times running alone; ...` | One task needed more memory than the machine has, even with no other task running. The local engine already runs fewer tasks at once when memory is short, and reruns a task whose worker was stopped. When the task ran out of memory itself, the message names the largest record it held, as in `the largest record of the <n> it was packing is id <id> of <table>, <x> MiB as read` or `the largest records of the <n> pair(s) it was scoring are id1 <id>, <x> MiB packed, and id2 <id>, <y> MiB packed`. | Give Iris more memory, by closing other programs, or by raising `IRIS_MEMORY_GB` or the memory limit of its container or job. When the record named, or another record of the input, is large, for example a cell of several GB, shorten that value. |
| `worker processes ended <n> times before they could take a task (exit code <n>). A worker that ends before its first task failed while starting, ...` | The worker processes failed while starting, before any work, for example because they cannot import a module that the features, the model or the labeler need. Their error is printed above the message. | Read the error printed above the message. Set `IRIS_WORKERS=1` to see the error of one worker alone, and check that the Python of the workers can import `iris` and your modules. |
| `IRIS_WORKERS must be a positive integer, got '<value>'` | The setting holds something other than a positive whole number. | Set it to a number such as 4, or unset it. |
| `IRIS_MEMORY_GB must be a positive number of GiB, got '<value>'` | The setting holds something other than a positive number. | Set it to a number such as 8, or unset it. |
| `<path>: the local engine reads and writes paths of this machine, and a <scheme>:// URI names storage that Spark reaches. Pass Spark DataFrames to run on Spark.` | A URI such as `s3a://` was given to a function running on the local engine. | Use a local path, or read the data with Spark and pass Spark DataFrames. |

### The pool and labeling

| What you see | What it means | What to do |
|---|---|---|
| `percent must be in the range (0.0, 1.0]` | `down_sample` was given a percentage, such as 30, instead of a fraction. | Pass a fraction such as 0.3. |
| `the pool has <n> pairs, more than the 10,000,000 that active learning scores in each round; draw a pool with down_sample` | `label_al` was given more than 10,000,000 feature vectors as an Arrow dataset, such as all the feature vectors of a large candidate set. | Draw a pool with `down_sample`, and pass it to `create_seeds` and `label_al`. |
| `create_seeds was asked for <n> seeds, and only <n> of the <n> feature vectors have a '<score_column>' to draw them by; ask for at most <n> seeds` | The pool has fewer pairs with a score than `nseeds`. | Ask for fewer seeds, or draw a larger pool. |
| `every '<score_column>' of the <n> feature vectors is missing or NaN, and create_seeds draws seeds by that score; pass the feature vectors as featurize gives them, with a score for each pair, or name another column with score_column` | No pair of the pool has a score. On the local engine, a pool without scores is ranked by the gold set instead when the labeler is a `GoldLabeler`. | Pass the feature vectors as `featurize` returned them, or name another column with `score_column`. |
| `create_seeds was given no feature vectors, so there is no pair to draw seeds from` | The pool is empty. | Check the candidate set, and the `percent` given to `down_sample`. |
| `No seeds were labeled before stopping` | The labeler gave the stop label before it labeled any pair as a match or a non-match, so `create_seeds` collected no labels. | Run `create_seeds` again, and label at least one match and one non-match before stopping. |
| `the directory of the checkpoint '<path>' does not exist` or `the checkpoint '<path>' cannot be written; pass a checkpoint_path in a directory this process may write to` | `create_seeds` or `label_al` cannot write its checkpoint file, and stopped before it asked for any label. | Create the directory, or pass a `checkpoint_path` in a directory that you may write to. |
| `<labeler> gave <value> as the label of (<id1>, <id2>); a label is 1.0 (match), 0.0 (non-match), 2.0 (unsure) or -1.0 (stop)` | A labeler returned another value, such as 0.5, `NaN` or text. | Make the labeler return one of the four values of [the contract](technical-guide.md#the-contract). |
| `ran out of candidates with <n> positive / <n> negative seeds; active learning needs at least one of each` | A warning from `create_seeds`. Neither end of the score ranking held a pair of the missing class. | See the next row. |
| `active learning needs both matches and non-matches to start, but the seeds are <n> positive / <n> negative. create_seeds ranks candidates by the score column and labels from both ends, so this means one end contained no example of its class -- common when a score is inflated by records agreeing on empty or null fields. Raise nseeds, supply seeds directly, or use a score column that separates the classes.` | The seeds hold only one class, so no matcher can be trained. | Do what the message says. Check also that the labeler labels correctly, for example that the gold set uses the same ids as the tables. |
| `existing training data at '<path>' has <n>-element feature vectors but this run produces <n>. That file is treated as a resume checkpoint, so it is almost certainly left over from a different dataset or feature set. Delete it, or pass checkpoint_path=<new path> to start fresh.` | The checkpoint file holds labels from another run. | Delete the file, or name another with `checkpoint_path`. |
| `Resuming from <n> labeled examples in '<path>'; create_seeds keeps them and labels only the seeds still missing. Delete that file or pass checkpoint_path=<new path> to start fresh.` or `Resuming active learning from <n> labeled examples in '<path>'; the supplied seeds are ignored. Delete that file or pass checkpoint_path=<new path> to start fresh.` | A warning. The checkpoint file holds labels from an earlier run, and labeling continues from them. | Nothing when resuming is intended. Otherwise delete the file or name another. |
| `max_labeled (<n>) is ignored while on_demand_stop is True, and <labeler> never stops on its own: labeling goes on until every pair of the pool is labeled. Pass on_demand_stop=False to end at max_labeled.` | A warning from `label_al` in continuous mode with a `GoldLabeler` or a `DelayedGoldLabeler`, which never gives the stop label. | Pass `on_demand_stop=False` to end at `max_labeled` labels. |
| `GoldLabeler: <column>=<value> has type <type> but the gold set holds <column> values of type [...]. Every pair would be labeled 0.0. Normalize the gold and record id dtypes to match.` | The ids of the gold set and of the tables have different types, such as text and integers. | Convert the gold set's ids to the type of the tables' ids. |
| `GoldLabeler: the gold set is empty, so every pair will be labeled 0.0` | A warning. The gold set has no pairs. | Check the path of the gold set. |
| `GoldLabeler: the gold pairs contain null ids (<n> in id1, <n> in id2); every gold pair names two records, so drop the pairs without an id` | The gold set has integer id columns with missing values. | Drop the gold pairs without an id, for example with `gold.dropna()`. |
| `'<package>' is required for this labeler but is not installed. Install the browser labeling support of Iris with: pip install 'iris[web]'` | `WebUILabeler` needs the browser labeling support, which is not installed. | Run the command in the message. |
| `could not bind the labeler's Flask port <port> on <host>: <error>. A previous labeling session may still be running -- stop it (e.g. ...), or pass a different flask_port to WebUILabeler.` | The port of the browser labeler is in use. | Stop the earlier session, or pass another `flask_port`. |
| `the Streamlit labeling UI exited immediately with code <n>. Check that streamlit is installed (pip install "iris[web]") and that port <port> is free.` | The browser page of the labeler did not start. | Install the browser labeling support, and free the port or pass another `streamlit_port`. |
| `the labeling backend did not become ready within <n>s (flask port <port>, streamlit port <port>)` | The server of `WebUILabeler` did not answer within 30 seconds of starting. | Run the labeling again. If it repeats, install the browser labeling support with `pip install 'iris[web]'`, and pass other ports with `flask_port` and `streamlit_port`. |

### Training, applying and evaluating

| What you see | What it means | What to do |
|---|---|---|
| `training needs matches and non-matches, but the labels hold <n> match(es) and <n> non-match(es)` | The labeled pairs hold only one class once the unsure ones are left out. | Label more pairs, including at least one of each class. |
